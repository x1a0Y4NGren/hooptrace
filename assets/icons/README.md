# HoopTrace Icon Assets

`hooptrace-app-icon.png` is the 1024 x 1024 launcher icon master. Android mipmap and iOS AppIcon derivatives are generated from this file.

The mark was created specifically for HoopTrace during the 2026 release-preparation phase with OpenAI image generation and contains no third-party artwork. The master and all derivatives are distributed under the repository MIT License.

Generation direction: a flat, opaque off-white icon combining a simplified half basketball court, an orange shot trace, and restrained red/blue player markers. No text or external brand marks are included.
