# HoopTrace 1.0.0

## 中文

HoopTrace 1.0 将首版原型完善为可靠的离线单挑记录与成长工具：

- 全新的“黑场编辑部”界面，统一首页、赛前、计分、回放、历史、球员、规则与设置；
- 统一计分模式：既可先点球场再选择分值，也可先得分并在 10 秒内补记位置；
- 对称四行计分操作、逐步撤回、显式暂停/结束流程，以及离线飞球与颜料落点动效；
- 可恢复的唯一活动比赛、计时/加时、目标分确认和可纠正球权；
- 分页历史、归档/删除、完整赛后修正与不可变审计记录；
- 基于真实记录完整度的单场/生涯分析、7/30/90 天和对手筛选；
- 版本化 JSON 备份，安全替换、确定性合并、用户授权目录自动备份与保留策略；
- 完整简体中文/英文、系统/浅色/深色主题、200% 字体与自适应大屏支持；
- Android 16 适配、性能门槛、API 36 CI、可复现未签名构建与 iOS 无签名编译。

隐私承诺不变：无账号、无云同步、无广告、无追踪、无运营后端；核心流程完全
离线。自动备份默认关闭，只写入用户明确授权的目录。

重要升级说明：1.0 不迁移 v0.1 数据库或备份。请先从 v0.1 导出需要保留的资料，
再清除旧应用数据后安装 1.0。应用会阻断旧库并解释原因，不会静默清空。

本版本优先发布 Android APK；iOS 尚未正式发布。详见
[隐私政策](https://github.com/x1a0Y4NGren/hooptrace/blob/v1.0.0/PRIVACY.md)。

## English

HoopTrace 1.0 turns the first prototype into a reliable offline 1v1 recording
and player-development tool:

- a new editorial interface shared by home, pre-game, scoring, replay, history,
  players, rules, and settings;
- one unified scoring mode supporting either court-first recording or immediate
  scoring with a ten-second location supplement window;
- symmetrical four-action scoring rails, step-by-step undo, explicit pause and
  finish controls, plus offline ball-flight and paint-impact feedback;
- one recoverable active match, count-up/countdown/OT clocks, finish decisions,
  and correctable possession records;
- paged history, archive/delete controls, complete post-game corrections, and
  immutable human-readable audit history;
- truthful single-match and career analytics with 7/30/90-day and opponent
  filters, never inventing efficiency from incomplete tracking;
- versioned JSON backup with safe replace, deterministic merge, optional SAF
  automatic backup, and bounded retention;
- complete Simplified Chinese/English, system/light/dark themes, 200% text, and
  adaptive large-screen behavior;
- Android 16 hardening, performance gates, API 36 CI, reproducible unsigned
  builds, and a macOS iOS no-sign compile gate.

The privacy promise is unchanged: no account, cloud sync, ads, tracking,
telemetry, or project backend. Core use is fully offline. Automatic backup is
off by default and writes only to a user-approved directory.

Important upgrade note: 1.0 does not migrate v0.1 databases or backups. Export
anything needed from v0.1, then clear the old app data before installing 1.0.
The app blocks and explains legacy data instead of silently wiping it.

This release ships an Android APK first; iOS is not yet formally distributed.
See the [privacy policy](https://github.com/x1a0Y4NGren/hooptrace/blob/v1.0.0/PRIVACY.md).
