# HoopTrace v0.1.0

HoopTrace 的首个 Android 公开版本，面向需要在球场边快速记录单挑比赛的篮球爱好者。应用永久免费开源，核心功能完全离线，不包含账号、广告、分析或追踪。

## 主要功能

- 横屏单挑计分，支持 1、2、3 分、犯规和自定义球员名称。
- 标准半场投篮落点记录，落点确认后避免现场误触。
- 比赛复盘、事件时间线、投篮图、历史记录和单场分析。
- 球员与规则模板管理，以及带审计记录的赛后修正。
- 完整 JSON 备份与恢复、CSV 导出、复盘图片分享。
- 用户授权目录中的可选自动本地备份，默认关闭。

## 隐私

比赛、球员、规则和设置默认只保存在设备本地。HoopTrace 没有运营后端，不会上传比赛数据，也不接入广告、分析、追踪或崩溃遥测 SDK。详情见 [隐私说明](https://github.com/x1a0Y4NGren/hooptrace/blob/v0.1.0/PRIVACY.md)。

## 安装与校验

1. 下载 `HoopTrace-v0.1.0-android.apk` 和 `SHA256SUMS`。
2. 校验 APK 的 SHA-256 与 `SHA256SUMS` 一致。
3. 在 Android 设备上允许当前文件来源安装 APK。

正式 APK 使用 HoopTrace 的永久 Android 发布证书签名。后续 GitHub 版本将沿用同一证书；不要安装来源不明或签名不同的同名 APK。

## 当前限制

- 首版最低支持 Android API 24。
- 首版界面以简体中文为主，其他界面语言将在后续版本补充。
- iOS 工程已保留，但本版本不提供 iOS 安装包。
- 不提供账号、云同步或跨设备自动同步。
- F-Droid 条目将在可复现构建与上游签名验证完成后另行提交。

完整变更见 [CHANGELOG.md](https://github.com/x1a0Y4NGren/hooptrace/blob/v0.1.0/CHANGELOG.md)。
