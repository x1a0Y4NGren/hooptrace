# Q 弹启动动画

用户于 2026-10-04 批准本方案。沿用正式 C 独眼球怪，启动静音、无震动。

## 动作参数

原生与 Flutter 共用 288dp 画布、0.78 基础缩放。标准动作共 1000ms：

| 时间（ms） | 姿态 |
| --- | --- |
| 0–60 | 原图静止，衔接原生启动画面 |
| 60–150 | 下沉蓄力，纵向压缩 8% |
| 150–330 | 跃起 12dp，纵向伸展 6% |
| 330–480 | 落地压缩 9% |
| 480–620 | 回弹 3dp，恢复身体比例 |
| 620–760 | 上侧局部余波向右滚动，最大位移 2dp |
| 760–860 | 原图静止收势 |
| 860–1000 | 淡出到应用页面 |

跳跃期间，上半部两次衰减水波最大位移 3dp，向身体中部和眼睛、嘴部保护区平滑减弱。收尾余波作用于上側约五分之一宽度，起止形变归零。48×48 纹理网格复用正式透明 PNG；不修改品牌源图。

## 启动契约

动画从可见首帧开始；图像预解码最多等待 100ms，偏好读取最多等待 80ms。页面尚未准备好时在原图静止姿态等待，超过 2 秒显示双语提示。错误和旧数据库保护页及时显示。点击最多 120ms 归零并跳过；减少动画仅淡出，关闭动画直接显示启动内容；同一进程不重复播放。数据库初始化顺序和比赛反馈设置保持原有行为。
